##  Turtle Hirst-Style Dot Painting

This Python project uses the **turtle** module to create a **Hirst-inspired dot painting**. The program draws multiple rows of colored dots, producing a visually appealing, abstract art piece.

---

###  How It Works

* A turtle named `tim` is used to draw the dots.
* A **predefined list of RGB colors** (`color_list`) is used for the dots.
* The turtle moves in a grid pattern, creating **10 dots per row** and 10 rows in total.
* The turtle is set to **fastest speed** and pen up to ensure smooth, quick drawing.
* Each dot has a fixed size (`20`) and is placed evenly spaced apart (`50` units).

---

###  Concepts Used

* Python `turtle` graphics
* RGB color system (`turtle.colormode(255)`)
* Lists and random selection for dynamic coloring
* Loops to repeat drawing actions and create rows
* Turtle movement and headings for grid positioning

---

💡 **Optional:** You can uncomment and use the `colorgram` section at the top to **extract colors from an image** and make the painting match a real palette.
